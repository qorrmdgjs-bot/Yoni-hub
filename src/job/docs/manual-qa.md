# 수동 검증 체크리스트 — Phase 1

`npm run dev` 후 http://localhost:5173 에서 순서대로 확인하세요.
자동 테스트로 이미 검증된 항목(계산 로직·가져오기 방어 55건)은 여기서 제외했고,
**실제로 눈으로 봐야만 알 수 있는 것**만 남겼습니다.

## B. 헤드헌터 기능

## F. 알려진 한계 (버그 아님)

- **PC와 폰의 데이터는 자동 동기화되지 않습니다.** 브라우저 저장 방식의 근본 한계로, JSON 내보내기/가져오기로 옮겨야 합니다.
- 브라우저 데이터(쿠키·사이트 데이터)를 삭제하면 모든 기록이 사라집니다. 주 1회 백업이 유일한 방어책입니다.
- **면접 탭**은 아직 만들지 않았고, 현재는 무엇이 올지 안내만 표시됩니다.
- **문서 관리 탭과 헤드헌터 CRM 탭은 만들지 않기로 했습니다.** 경력기술서는 한글/워드로 쓰고,
  헤드헌터 정보는 지원 건 상세 안에서 관리합니다 (같은 회사를 두 번 입력하지 않기 위해서입니다).
